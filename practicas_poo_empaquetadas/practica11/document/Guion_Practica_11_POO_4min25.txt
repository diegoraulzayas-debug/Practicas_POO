2. MARCO TEÓRICO

REDACTOR — 1:00 a 1:17 (17 segundos)
Para la interfaz utilizamos Swing, una biblioteca de Java que permite organizar ventanas y componentes. Por ejemplo, JFrame funciona como ventana principal; JButton permite ejecutar una acción; JLabel muestra información breve, y JTextArea presenta varias líneas de texto. Con JScrollPane podemos desplazarnos cuando el contenido supera el espacio visible.

NARRADOR — 1:17 a 1:33 (16 segundos)
La interacción se basa en eventos: cuando el usuario presiona un botón, un ActionListener ejecuta la acción asociada. Para leer el archivo usamos FileReader y BufferedReader, que permiten recorrer el contenido por líneas. Además, IOException ayuda a controlar problemas como una ruta inexistente o un archivo que no se puede leer.

4. DESARROLLO: IMPLEMENTACIÓN DEL PROGRAMA

DESARROLLADOR — 2:43 a 3:03 (20 segundos)
Para el programa separamos las responsabilidades en dos clases. AnalizadorDeArchivo se encarga de localizar, leer y procesar el documento; Main construye la ventana y responde a las acciones del usuario. Así, la lógica del análisis queda independiente de la presentación gráfica.

DESARROLLADOR — 3:03 a 3:22 (19 segundos)
Dentro de AnalizadorDeArchivo guardamos la referencia al archivo, el texto leído, el total de palabras y una bandera llamada archivoListo. El constructor verifica si el archivo existe, primero en la ruta indicada y después dentro de los recursos del paquete. Si no puede localizarlo, controla el problema mediante IOException y deja el indicador en falso.

NARRADOR — 3:22 a 3:41 (19 segundos)
Cuando el archivo está disponible, procesarArchivo lo abre con FileReader y BufferedReader. Después lee cada línea, la agrega al contenido completo y separa sus palabras usando los espacios. Solo cuenta los fragmentos que no están vacíos, por lo que los espacios consecutivos o las líneas en blanco no aumentan el resultado.

DESARROLLADOR — 3:41 a 3:57 (16 segundos)
Por otro lado, Main crea una ventana con un botón, una etiqueta y un área de texto que no se puede editar. Al presionar el botón, el ActionListener crea el analizador, procesa el archivo y actualiza la etiqueta con el total de palabras y el área central con el texto leído.
