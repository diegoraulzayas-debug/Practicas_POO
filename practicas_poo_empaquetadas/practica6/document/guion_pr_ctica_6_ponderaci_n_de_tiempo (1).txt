2. MARCO TEÓRICO Y PRESENTACIÓN DE LA PRÁCTICA — 0:25 a 0:55 (Duración de sección: 30 segundos)

(0:25 - 0:42) NARRADOR (17 seg) #2.1:
Para comprender el desarrollo, es importante distinguir tres elementos: los paquetes de Java, los archivos JAR y Javadoc. Los paquetes organizan las clases y ayudan a evitar conflictos de nombres. Los JAR reúnen clases compiladas y otros recursos en un solo archivo distribuible. Por último, Javadoc genera documentación técnica en formato HTML a partir del código fuente y sus comentarios.

(0:42 - 0:55) REDACTOR (13 seg) #2.2:
Estos elementos cumplen funciones diferentes, pero complementarias. Una organización clara permite mantener el código fuente separado de los archivos compilados, distribuir las aplicaciones y consultar la documentación de cada clase.

4. ORGANIZACIÓN Y EMPAQUETAMIENTO DE CLASES — 1:45 a 3:20 (Duración de sección: 95 segundos)

(1:45 - 2:03) NARRADOR (18 seg) #4.1:
La segunda actividad consistió en organizar las prácticas y el proyecto del semestre dentro de una carpeta principal. Se establecieron seis divisiones independientes y, dentro de cada trabajo, cuatro carpetas: src, test, library y document.

(2:03 - 2:21) DESARROLLADOR (18 seg) #4.2:
La carpeta src contiene los archivos fuente con extensión .java. La carpeta test almacena los archivos .class que se generan al compilar. La carpeta library reúne los archivos JAR, mientras que document contiene el reporte de la práctica y la documentación HTML generada.

(2:21 - 2:41) NARRADOR (20 seg) #4.3:
También fue importante respetar la relación entre los paquetes declarados en el código y la estructura de directorios. La ruta del paquete debe corresponder con la ubicación de las clases, tanto en las fuentes como en los archivos compilados. Así se conserva una organización consistente y se facilita localizar cada componente.

(2:41 - 3:00) DESARROLLADOR (19 seg) #4.4:
Para compilar, se indicó como entrada la carpeta de fuentes y como destino la carpeta de archivos binarios. Después, a partir de las clases compiladas, se creó un JAR para cada aplicación. Se configuró la clase principal en el manifiesto, lo que permitió ejecutar el archivo directamente mediante la máquina virtual de Java.

(3:00 - 3:20) EDITOR (20 seg) #4.5:
Finalmente, se utilizó Javadoc sobre los archivos fuente para generar páginas HTML con información de las clases y sus métodos. La documentación se guardó en la carpeta document, manteniendo separados los archivos editables, los productos compilados, los paquetes distribuibles y la información técnica.
