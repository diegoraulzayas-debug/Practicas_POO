NARRADOR:

En esta cuarta práctica de Programación Orientada a Objetos trabajamos dos temas principales relacionados con Java.

El primero fue el análisis del concepto de destructor y de las alternativas que existen en Java para la administración de memoria y la liberación de recursos.

El segundo consistió en desarrollar un analizador de palabras capaz de identificar y contabilizar palabras duplicadas dentro de una oración.


==================================================
0:15 – 0:38 | NARRADOR — OBJETIVOS
==================================================

[EN PANTALLA: objetivos de la práctica]

NARRADOR:

Los objetivos fueron analizar las respuestas de distintos modelos de lenguaje sobre el concepto de destructor en Java, desarrollar una aplicación para identificar palabras duplicadas e ignorar diferencias entre mayúsculas, minúsculas y signos de puntuación.

Finalmente, se buscó validar el programa con entradas que incluyeran caracteres especiales, acentos, la letra ñ, números y diferentes combinaciones de mayúsculas y minúsculas.

0:38 – 1:20 | REDACTOR — ACTIVIDAD 1 Y ANÁLISIS DE LLM
==================================================

[EN PANTALLA: Actividad 1 + los tres prompts]

REDACTOR:

En la primera actividad analizamos el concepto de destructor mediante tres consultas realizadas a modelos de lenguaje.

La primera consulta fue directa y permitió identificar una diferencia importante: Java no cuenta con destructores explícitos como C++. En su lugar, la memoria es administrada mediante el Garbage Collector.

La segunda respuesta utilizó diagramas de memoria y una comparación entre C++ y Java.

Finalmente, la tercera delimitó desde el inicio la diferencia entre ambos lenguajes y profundizó en mecanismos como AutoCloseable, try-with-resources, Cleaner y PhantomReference.

Al comparar las respuestas, observamos que mientras más específico fue el contexto proporcionado en el prompt, más estructurada y completa fue la respuesta obtenida.

1:38 – 2:30 | DESARROLLADOR — CÓDIGO
==================================================

[EN PANTALLA: IDE con AnalizadorPalabras abierto]

DESARROLLADOR:

Primero, la oración introducida por el usuario llega al constructor de AnalizadorPalabras.

Después se normaliza el texto convirtiéndolo a minúsculas, para considerar como iguales palabras que solamente cambian por el uso de mayúsculas.

[ZOOM AL CÓDIGO DE NORMALIZACIÓN]

Posteriormente se utiliza una expresión regular para limpiar la entrada y se divide la cadena en tokens utilizando los espacios como delimitadores.

[MOSTRAR contarPalabras()]

Cada palabra se utiliza como clave dentro de un HashMap.

Si ya existe, su frecuencia aumenta; si no existe, se agrega con una frecuencia inicial de uno.

Después se revisan las claves almacenadas para identificar cuáles tienen una frecuencia mayor a uno.

[RESALTAR HashMap<String, Integer>]

Finalmente, los duplicados pueden mostrarse directamente o almacenarse en un TreeSet para presentarlos en orden alfabético.

[CORTE A Main]

Desde Main se captura la oración mediante Scanner, se crea el objeto AnalizadorPalabras y se llaman los métodos encargados de mostrar las frecuencias y los duplicados.

==================================================

[EN PANTALLA: resultados + código + diagramas]

NARRADOR:

A partir de las pruebas realizadas, comprobamos que la combinación de expresiones regulares y HashMap permite identificar palabras duplicadas independientemente de las variaciones de formato presentes en la entrada.

Además, TreeSet permite presentar los duplicados en orden alfabético cuando así se solicita.

Por otra parte, el análisis de los modelos de lenguaje permitió observar una diferencia fundamental entre C++ y Java respecto al manejo de la memoria.

En Java no existen destructores explícitos como en C++. La memoria es administrada mediante el Garbage Collector, mientras que para recursos externos pueden utilizarse mecanismos como AutoCloseable y try-with-resources.

En conjunto, la práctica permitió relacionar programación orientada a objetos, procesamiento de cadenas, expresiones regulares y estructuras de datos dentro de una misma solución.
